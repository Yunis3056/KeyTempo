# KeyTempo · 键奏 使用指南

下载 GitHub Releases 中的 `KeyTempo.exe` 后双击即可运行，无需安装 .NET。也可选择便携 ZIP（包含文档）或安装版（创建快捷方式并支持卸载）。

## 每隔 5 分钟发送一次按键

1. 运行程序，选择一个键盘动作。首次启动的按键为空，不会默认发送 `Z` 或其他键。
2. 从按键列表选择按键，或者启动录制并按下要发送的单键 / 组合键。录制后确认显示的内容正确。
3. 选择固定间隔，输入 `300` 秒。关闭随机模式可获得固定周期。
4. 选择首次执行方式：先等待会在开始后等待一个完整间隔；立即执行会在开始时发送第一次输入。
5. 绑定要操作的目标窗口。在需要切换窗口的录制过程中，根据界面提示切换到目标程序。
6. 让目标窗口位于前台，按 `F8` 开始。若在控制台按开始，会留出 3 秒供你切换到目标窗口。

状态区域会显示倒计时、执行次数、最近执行和下次计划时间。`F8` 暂停 / 继续；`F9` 停止并清除本轮计时、计数。快捷键可以在设置中更改；注册失败时选择未被其他程序占用的组合。

## 多动作与随机间隔

每个动作的间隔和启用开关独立。开始前启用需要运行的动作；编辑完成后按界面提示保存应用。

| 模式 | 配置示例 | 行为 |
| --- | --- | --- |
| 固定 | 300 秒 | 每周期使用同一个间隔 |
| 随机范围 | 最小 270、最大 330 秒 | 每周期重新选择范围内间隔 |
| 中心 / 幅度 | 中心 300、幅度 30 秒 | 在 270–330 秒之间重新选择 |

程序是普通桌面定时器，实际执行可能受系统调度、机器负载和一个动作所需时间影响，不用于硬实时控制。休眠后不会突发补发过去的周期。

## 鼠标位置序列

1. 创建鼠标动作，选择左 / 右键、单击 / 双击。
2. 选择坐标方式。屏幕绝对坐标适合固定桌面位置；窗口相对坐标适合会移动的目标窗口。
3. 绑定目标窗口，进入位置录制，移动鼠标到目标位置，按 F6 逐个添加位置，按 F7 完成。
4. 确认位置顺序并设置位置之间的等待时间。
5. 每到一个周期，程序依次点击整个位置序列，之后继续下一个周期。

窗口相对坐标跟随窗口平移，不识别按钮内容。目标窗口大小、缩放或页面布局变化后，原位置可能不再对应原按钮，应重新录制。更改显示器排列后也应检查屏幕坐标。

## 目标窗口与异常处理

锁定目标窗口用于确认“当前前台窗口是否就是指定窗口”。程序不会强制激活目标窗口，也不会承诺后台输入。程序发现目标失效、前台窗口不匹配、输入被系统拒绝或坐标无效时，按设置中的对应策略暂停或跳过，并记录原因。

暂停后请先处理提示原因，再回到正确窗口并继续。窗口已关闭并重开时，需要重新记录目标。运行权限默认与普通桌面应用相同；如果目标以管理员权限运行，Windows 可能拒绝注入，需按日志判断。普通权限应用不能自动提升到目标权限。

## 托盘、外观与反馈

最小化后程序进入系统托盘；双击托盘图标可以恢复窗口。托盘菜单可控制运行并退出。关闭 / 退出会结束本次运行，重新启动不会自动开始发送输入。

设置中可以选择深色 / 浅色主题、强调色、透明度和动效档位。省电档减少动画；标准 / 炫酷档提供更丰富的反馈。声音、桌面通知可按需要开关。Windows 通知设置可能抑制通知弹出，以程序状态和日志为准。

## 配置、隐私与更新

动作与外观配置自动保存在 `%LOCALAPPDATA%\AutoPilotInput\settings.json`，导出 / 导入用于备份与迁移。运行状态和已绑定的活动窗口不会被当作可靠的跨启动目标；每次启动检查目标再开始。

程序默认不联网、不上传配置，也没有遥测。只有主动点击“检查更新”才访问配置的 GitHub 仓库；仓库字段应填写真实的 `owner/repository`。没有配置仓库或仓库未发布 Release 时，无法得到更新版本。更新通过浏览器手动下载，不在后台安装。

## 常见问题

**为什么开始按钮提示没有按键？** 这是有意的初始状态。先选择或录制目标按键。

**为何切换到浏览器后暂停了？** 当前前台窗口与锁定目标不同。切回目标窗口并继续，或根据自己的场景调整异常策略。

**为什么显示执行但目标没有反应？** 先使用记事本核对按键，检查目标权限与当前焦点。某些程序只接收特定输入源，Windows 的注入成功也不保证目标业务逻辑已经响应。

**快捷键无效？** 检查程序是否正在运行、全局快捷键是否注册成功，及是否与目标软件或系统快捷键冲突。

**单文件为什么体积较大？** 便携版本包含所需 .NET 运行时，用户不需要安装开发环境。
